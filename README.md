# 🍕 Pizza Ordering System

A simple Python portfolio project demonstrating list manipulation, sorting, and price analysis for a pizza shop.

## What it does

- Stores a list of pizza toppings
- Stores corresponding prices
- Counts how many pizzas cost $2
- Calculates how many different pizzas are available
- Sorts pizzas by price
- Identifies the cheapest and most expensive options
- Updates the menu by removing the priciest item and adding a new option
- Displays the three cheapest pizzas

## Run it

```bash
python pizza_ordering.py
```
