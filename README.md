# 🍕 Sunset Pizza Co.

A polished beginner-friendly Python portfolio project that simulates a pizza ordering system.

## Overview

This project lets users:
- browse a pizza menu,
- select a pizza,
- add optional toppings,
- build a multi-item order,
- calculate subtotal, tax, and total,
- print a simple customer receipt.

## Features

- Clean menu display with pricing
- Custom topping selection
- Multiple pizza ordering support
- Automatic tax calculation
- Professional-style receipt output
- Beginner-friendly code structure for learning and portfolio presentation

## How to Run

```bash
python pizza_ordering.py
```
